# Build 12 console artwork and identity data

Four original console illustrations were generated with the built-in image_gen tool. Saved assets and exact prompts are recorded in prompts.json. They are generic menu backgrounds, not gameplay.

The compact Title-IDs.json lookup retains only title names and release IDs from the pinned Azahar 2127.0-rc1 compatibility data in Vendor/Azahar/Source/dist/compatibility_list/compatibility_list.json. It does not include keys, system data or games. Source: https://github.com/azahar-emu/compatibility-list . The pinned full upstream source and its GPL-3.0-or-later notice remain in the corresponding-source package.
