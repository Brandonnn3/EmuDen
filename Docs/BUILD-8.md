# Build 8: console polish and original menu audio

The console home now has a compact system selector, a glass-to-cyan cover focus ring, a softly lit Start/Continue button and a clearer settings screen. Collection remains available from the grid button in the header; search and cover artwork behavior are preserved.

PSP, PlayStation (PS1) and GameCube have individual preview pages with original hardware-inspired silhouettes. Each says Coming soon and explicitly states that it is not playable. There is no launch route for an unavailable core. Back to 3DS library restores the playable shelf; adding games returns to 3DS first. No support dates or extra supported file types are implied.

## Original sound palette

Five short struck-glass cues cover focus, confirmation, back, launch and coming-soon selection. They are generated by `Scripts/generate-menu-audio.py` from sine oscillators, decaying inharmonic partials and abstract interval gestures. No sampled audio, third-party game sounds or quoted game melodies are used. Deterministic 44.1 kHz stereo PCM assets and their provenance notice are in `Resources/MenuAudio`.

Console settings provides a persistent Button sounds switch, volume slider and preview. The ambient audio category follows Silent Mode and mixes with other audio. Focus changes are rate-limited to 75 ms. Players are prepared while the menu is active to avoid first-press setup work. A launch flourish finishes before opening the player; silent/disabled audio adds no delay. All menu players stop when gameplay begins or the app becomes inactive. The menu does not deactivate the shared audio session used by the emulator.

Controllers retain left/right game selection, confirm, back and settings. Shoulder buttons switch systems, and confirming a coming-soon page returns to 3DS. The menu releases its element handlers during gameplay. Phone speaker balance, Silent Mode behavior and physical controller feel still need a device listening check.

No emulator-core, rendering accuracy, clock, resolution or shader settings changed in this pass. User games, saves, Mii resources and downloaded game covers remain outside the distributable.

## Validation

Run `python3 Scripts/generate-menu-audio.py --check` to check every bundled cue against the deterministic synthesis, its format, duration and unclipped, zero-ended PCM. `build/EmuDen-Menu-Sound-Preview.wav` is a development-only audition in focus/confirm/back/launch/coming-soon order.

Release Duo UI checks cover coming-soon gating and return, persisted sound mute and preview availability, the real-game shelf/search/collection and launch/return path, both fold fixtures, Mii setup, and Quick Save/Load/relaunch/resume. Final results and archive validation are recorded in `TestFlight/STATUS.md`.

The six-test Release run passed in `build/EmuDen-Build8-Final.xcresult`. Visual review led to smaller responsive console silhouettes, a full return button above the dock, an icon header for narrow book panels, a consistent blue settings tint and removal of a clipped decorative swipe hint. The three focused follow-up checks passed in `build/EmuDen-Build8-Layout.xcresult`; the final launch/return check passed in `build/EmuDen-Build8-Home-Final.xcresult`. Earlier candidate archives are retained under `build/Build8-UI-Candidates`, outside the current TestFlight artifact folder.
