# EmuDen handheld icon

Original image generated with the built-in image_gen tool on 2026-11-11 for EmuDen. A sculpted horizontal handheld combines a directional cross, four face buttons and a cyan/violet portal display. Ice-blue optical glass and pearlescent ceramic sit against an electric-indigo background. There is no lettering, game character or manufacturer branding.

`EmuDen-Icon-Master.png` is the unchanged square master. `swift Scripts/render-app-icon.swift` exports the opaque RGB 1024×1024 App Store icon to `Resources/Assets.xcassets/AppIcon.appiconset/AppIcon.png`; iOS supplies its outer mask. The source package includes both the master and exporter. The earlier lime icon remains in build 13. The rejected glass E master and intermediate archive remain in private build backups and are excluded from the source package.

Generation brief: a single bold readable handheld game console with pale glass/ceramic materials, dark directional cross and circular buttons, a simple glowing cyan-violet portal on its inset screen, controlled dimensional lighting and no text, logos, decorative particles or proprietary console casing. Full-bleed opaque square artwork, legible at home-screen size.
