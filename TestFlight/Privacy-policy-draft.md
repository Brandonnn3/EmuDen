# Privacy reference — build38

Public policy: https://emuden-support.headyopossum2.chatgpt.site/privacy.html. This reference must match the public policy and live Store label before submission.

No EmuDen account, advertising/tracking SDK, automatic diagnostic upload or default artwork provider. Game files/resources, native saves, snapshots, library/custom names, selected/cached images, widget data and device-motion/age-band results remain local. CoreMotion and age-band values are transient; no birth date or identity document is collected by EmuDen. Apple services and file-provider/OS backups have their own practices. Guest software may have its own emulated networking; it is not promised disabled.

Users may preview/connect a chosen HTTPS artwork catalog or separate3DS cover folder. Matching is local; the host receives requested paths and connection data. For developer-operated hosting, Cloudflare documents IP/traffic processing, stored network security/availability data and purpose-based retention. Disclose Product Interaction and Other Data Types, linked, App Functionality only, trackingNo. This is an engineering mapping of actual request scope and provider policy; no fixed log retention or provider-wide audit is claimed. No location extraction, stable app/device ID, gameplay file, complete library, save, motion, age-result or picture upload is added. Arbitrary user-selected sources control their own practices. Transfers stop for gameplay/background/disconnect; offline/manual images remain.

Native downloads do not execute website scripts. Support/privacy links open external Safari; website security scripts/cookies and web traffic are described separately. Voluntary external email or shared logs may be retained to handle the request; no automatic email/upload. Contact the public support address for developer-held correspondence; external provider logs/backups follow their policies.
