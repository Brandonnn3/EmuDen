# EmuDen support — draft for later public hosting

EmuDen 0.1.0 currently supports Nintendo 3DS emulation on iPhone and iPad. Other console cores are not available yet.

To try the included open-source test, open System → Launch 3DS test. Add your own compatible, decrypted game through Add games. No commercial game, Nintendo system archive or console key is supplied.

For a problem report, include the app build, device, iOS version, game, scene, FPS and reproduction steps. Note whether a controller or console system-data folder was used. Use TestFlight feedback for this internal beta. Do not send ROMs, firmware, console keys or personal Mii databases.

Some Mii-dependent games need the console's Mii resource archive; a saved Mii database does not include its head models. The built-in guest face is a fallback. Performance and compatibility vary by title.

This draft has not been published and has no public URL yet.
