# Open-source distribution record — build 19

This records implementation evidence, not a legal opinion about every distribution arrangement.

- **Owner's grant:** LICENSE.txt, COPYRIGHT.md and Docs/Legal/OWNER-AUTHORIZATION-2026-11-11.json record GPL-3.0-or-later for original EmuDen source contributions in build 17 onward. Existing third-party notices/terms are preserved. The grant does not convey publisher-artwork or trademark rights.
- **GPLv3 sections 4–5:** matching packages include the license, original upstream notices, modified app/core sources or deterministic patches, and build instructions. The versioned release notes identify changes. The combined software is distributed under GPL-compatible terms as applicable, rather than assigning a proprietary license to original frontend code.
- **Section 6 source access:** https://github.com/Brandonnn3/EmuDen provides source-only releases associated with build numbers. Exact package checksums are shown in the source page and releases; anonymous downloads are independently verified. Maintain this access for recipients and retain earlier releases when distributing their binaries. An unmodified upstream link is insufficient for EmuDen's local changes.
- **Build and installation material:** TestFlight/SOURCE.md, the Xcode project, app/extension entitlements, shared App Group instructions, pinned upstream release, local patches and MoltenVK fetch/build recipe permit rebuilding with one's own signing and identifiers. Apple's Xcode SDK and credentials are not redistributable project inputs. Device installation remains subject to Apple's platform signing controls. The extent of any GPLv3 Installation Information duty in a particular distribution has not been certified by this record; no signing keys are published.
- **Attribution:** Resources/ThirdPartyNotices.txt and Docs/Legal/Notice-Sources.json preserve 84 component/header notice texts. The same text is bundled and accessible offline in Settings. The generator scans a conservative superset of upstream component notices; this is not a claim that every optional component is linked. The complete pinned unified core source includes its dependencies, and the MoltenVK build recipe pins its sources and dependencies.
- **Store terms:** GPL-family licensing is not an automatic App Store prohibition. Apple's Standard EULA has an open-source exception in the copying/reverse-engineering clause; that is not a blanket exception to all distribution restrictions. Its Developer Program License Agreement requires compliance with applicable FOSS terms. Source publication addresses source availability; it does not independently resolve every interaction with store conditions, platform controls or any custom agreement. No new Apple agreement or custom EULA has been accepted/submitted by this work. Verify the actual distribution terms before a public submission and obtain qualified advice for unresolved conflicts.
