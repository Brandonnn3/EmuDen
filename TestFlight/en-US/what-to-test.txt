Build 21 release controls. Build 18 remains the owner's current phone test build; no new core/graphics speed gain is claimed in build 19.

Privacy, access and optional support:
• First library use asks whether to download online artwork. Decline, relaunch and verify the choice persists; bundled/cached/chosen pictures remain. Settings → Online artwork changes the choice.
• Imported games, links and widgets require declared adult access. An under-18 choice blocks imported titles; the bundled Homebrew Menu demo remains available. In applicable regions on supported iOS, Apple must return an adult age band. Regional sandbox/device validation remains required.
• Release console menus offer only playable 3DS. Verify HTTPS game links from another app on the installed device; missing local entries should show a useful error. Check Privacy, Support, Source and offline Open-source notices in Settings.
• Tips appear only if Apple returns configured products. All features stay free. Use StoreKit local tests or Apple's sandbox, never a real purchase. Without available products, there should be no tip card or unfinished purchase screen.

Saves:
• Make multiple Quick Saves at distinct moments. Save history should show dates/thumbnails and let you load an earlier point. It keeps 10 manual and 3 automatic points per game.
• Leave through Return to library, relaunch and check Resume session. With automatic points on, background/exit and five minutes of active play should capture points. A force-quit can interrupt an unfinished capture.
• Use the game's own Save/Continue too. Native in-game saves and emulator snapshots are separate; switching games should preserve both. Back up before uninstalling or changing system data.

Graphics and gameplay:
• Dark Moon: use 1× with Reduce shader pauses on. Repeat the first outdoor route/ghost window, then revisit in the same session. Record lowest FPS and pause duration. Try preparing known shaders after those scenes have been cached. Exact phone gains remain unmeasured.
• Repeat Mario Golf's perfect-max Donkey Kong shot; check 3×, audio, Mii faces, native saves and history. Original faces require authorized shared head resources; a saved Mii database is different. The Settings portrait is a separately chosen local picture.
• Long-press a cover → Game settings. Verify independent 1×–3× resolution, texture sampling and shader preferences; disabling customization restores defaults. During play, changes apply on resume.
• Automatic quality is optional/off by default. It treats chosen resolution as a ceiling, reduces it after sustained slowdown/heat and recovers slowly. It cannot go below 1× or eliminate an unseen shader stall. Shader preparation can lengthen startup.
• Controller → Duo layout → Fill display should remove the outer-screen inset. Check orientations, inner folding, touch edges, button hiding/haptics and upper-toolbar fading. FPS and frame-time graph are separate optional displays.

Library and widgets:
• Test search/dock hiding, fast cover selection, offline artwork and Reduced Motion. Build21 uses original console art and personal image imports only; the earlier generated collection is preserved outside this release.
• Add Continue Playing/Recent Games widgets. Check cached images, appearance, recent ordering, game links and save-before-switch. Actual Home Screen/regional age-service behavior still needs phone checks.

Only 3DS is playable. No commercial ROMs or Nintendo system archives are included. Report device/build, title, settings, scene and reproducible steps.
