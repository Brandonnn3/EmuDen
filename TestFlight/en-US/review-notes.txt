EmuDen 0.1.0 supports Nintendo 3DS emulation on iPhone and iPad. No login is required. The initial public release is planned as free in the United States. Only 3DS is offered as playable.

Test without commercial content:
1. Open Settings in the bottom dock.
2. Open Help, tests & open-source notices → Launch 3DS test.
3. The included 3DS Homebrew Menu 2.4.4 runs in the emulator. Wait for startup, then check displays, touch and controls.
4. Tap the upper display to reveal controls → menu for pause, Quick Save, Quick Load and Save history. Return to library captures a resume point when enabled.
5. Test controls opens a separate native input/display diagnostic.

No Nintendo game, firmware, console key or original Mii archive is bundled or offered for download. Users import compatible decrypted software through Files. The included homebrew's license/credits and third-party notices are accessible offline in Settings. Mii system data and a local profile picture are separate optional imports.

Azahar 2127.0-rc1 uses the FastInterp CPU interpreter and Vulkan/Metal graphics through MoltenVK 1.4.2. CPU/shader JIT is disabled. Corresponding source, local patches and rebuilding instructions are published by build number at https://github.com/Brandonnn3/EmuDen and linked in Settings. No private signing keys or user files are in that source.

The local library lists imported titles; its menu provides a universal link and labels imported software as unrated. Links open an existing local entry, never download a game. Imported software requires a local adult declaration. On supported iOS versions, regional age-assurance eligibility is checked with Apple's Declared Age Range service; required checks must confirm an adult band. The bundled demo remains available without that declaration.

Optional developer tips, if configured with Apple, are repeatable consumables with no feature/content unlock. Settings displays only products returned by StoreKit, at Apple's localized prices. With no available products, the tip section is absent and the app remains free. The WidgetKit extension reads local metadata and cached images; it makes no network requests. No ads, subscription, messaging or game-download service is included.

Performance and compatibility vary by title/device. The owner is validating physical-device gameplay separately. The preparation records do not assert public rights clearance or prior Apple approval; resolve the recorded release holds before submitting this candidate.
