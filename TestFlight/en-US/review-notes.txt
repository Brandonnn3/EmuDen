EmuDen 0.1.0 (38) supports compatible Nintendo 3DS, PlayStation and GameCube software. No sign-in is required.

The app does not supply or download commercial games, proprietary firmware, console BIOS, Nintendo console keys or original Mii resources. It includes licensed Homebrew Menu 2.4.4 for 3DS and original source-built PS1/GameCube diagnostics, so the core features can be reviewed without a commercial game.

Review path:
1. Use the console picker at the top to select Nintendo 3DS, PlayStation or GameCube. The Library console picker filters without leaving Library; Home uses the favorite console configured in Settings.
2. For 3DS, open Settings > Help, tests & open-source notices > Launch 3DS test.
3. In an empty PlayStation or GameCube library, choose Try the PS1 demo or Try the GameCube demo.
4. During play, open the game menu for Quick Save, Quick Load, save history and Graphics settings. Saving uses a small passive banner; the atomic core snapshot may briefly hitch. Loads deliberately pause to restore state.
5. Touch controls are movable. Compatible external controllers are supported. The console-specific controller preview opens from the controller button.

All game files, local saves, custom names, selected images, control layouts and widget snapshots stay local, subject to the user’s OS/file-provider backup settings. Optional HTTPS artwork catalogs and a separate 3DS cover-folder source are user-selected, never prefilled or enabled by default. Hosts receive the requested paths and normal connection information. ROMs, saves, avatars, Mii data and the full library are not uploaded. Artwork transfers stop during gameplay and backgrounding; cached images remain available offline.

Supported iOS checks Apple regional age eligibility and requests an age band only where applicable. The blanket local adult declaration and Unrated game labels are removed. No birth date or identity document is collected by EmuDen. 3DS CoreMotion input is transient and stops on pause/background/close.

All guest CPUs use interpreters. No private JIT broker or executable-memory bypass is used. Graphics choices depend on the core; compatibility and performance vary. Optional Apple consumable tips never unlock features and are hidden when products are unavailable.

No demonstration account is needed. The Apple-only review contact is supplied in App Review Information.

The public software index lists the supplied demos: https://emuden-support.headyopossum2.chatgpt.site/software.html . Share links for local imported games work through universal UUID URLs across all three consoles. PS1/GameCube diagnostic launch buttons are local navigation; there is no hosted commercial game catalog or download service.

Known compatibility issue: Detective Pikachu (3DS) can stall while creating native save data. The owner deferred this title-specific investigation; this release does not claim a fix. The included original/licensed demos provide review paths without commercial content.
